# 单词库核心模块

本目录是单词应用新版本的独立领域层，当前不修改旧页面，也不依赖第三方包。

## 当前能力

- 创建、重命名和深拷贝词库
- 手动添加单词
- 同一词库中按规范化英文合并单词
- 英文相同、词性相同：合并去重后的中文释义
- 英文相同、词性不同：保留不同词性
- 修改词条
- 软删除、恢复、30 天后清理
- 搜索已保存单词：英文和中文的完全、前缀、包含匹配
- 指定一个或多个词库进行本地搜索
